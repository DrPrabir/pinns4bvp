# Third-party software

PINNs4BVP depends on or optionally integrates with the following open-source
Python projects.  Their respective licenses apply to those projects.

- **NumPy** — numerical arrays and numerical operations — BSD 3-Clause.
- **SciPy** — classical `scipy.integrate.solve_bvp` backend — BSD 3-Clause.
- **Matplotlib** — optional plotting — Matplotlib license.
- **PyTorch** — optional PINN backend, automatic differentiation, Adam and
  L-BFGS optimization — BSD-style license.
- **pytest** — development testing — MIT.
- **setuptools / wheel** — Python packaging tools.

PINNs4BVP itself is distributed under the MIT License in `LICENSE`.
